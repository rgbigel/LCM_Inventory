📖 CM Control Hub User Guide & Operational Manual

1. Two-Tier Proposal & Progress State Lifecycle

Plan State:

  • 🐛 Bug: Raw error intake / issue feedback below suggested. Can be promoted to Suggested or Approved.
  • 💡 Suggested: Idea registered for review; requires operator approval before execution.
  • Approved: Formally approved; queued for AI agent implementation.
  • ⏸️ Deferred: Postponed to future milestone.
  • ❌ Rejected: Dropped / cancelled.
  • ✅ Completed: Formally reviewed, accepted, and committed in Git.

Progress State:

  • Undecided: Initial unstarted state.
  • Queued (Ready): Approved and placed in implementation queue.
  • ⚡ In Progress: Active implementation / agent development.
  • ⏳ Verification: Implementation complete; awaiting Beyond Compare visual review.
  • Completed: Review accepted and dual-commit sync complete.

2. Beyond Compare 5 Visual Review Gate

Click 🔍 BC5 to open Beyond Compare 5 with the Variant A baseline:
Left: Workspace_Inventory\scratch\BC_Review\<CRP>_<Repo>_<CommitSha> (Baseline)
Right: Target Repository Working Directory (Current Live)

  • Copy Right → Left: Stages modifications for acceptance.
  • Type 'Delete' on Left: Permanently deletes file on disk and in Git.
  • Type 'Rename to X' on Left: Renames file and cleans up old file.

3. ACCEPT Gating Invariants

The ACCEPT and ACCEPT SELECTED actions are strictly gated:

  • Only proposals in ⏳ Verification, ⚡ In Progress, or Approved state can be accepted.
  • Proposals in Undecided, Deferred, Blocked, or Rejected state cannot be accidentally accepted.

4. Interactive CM Console (Bottom Dock)

Type commands directly into the bottom console to control the CM engine:
do #<id> • review #<id> • accept #<id> • defer #<id> • status • readiness
