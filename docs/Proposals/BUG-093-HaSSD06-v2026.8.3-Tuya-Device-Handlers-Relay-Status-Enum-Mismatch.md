# BUG-093: Tuya Device Handlers Invalid Enum Value for Datapoint `relay_status`

## 1. Defect Description & Discovery Vector
During Tuya integration startup, the following schema violation warning is repeatedly recorded:
```
Found invalid ENUM value `off` (<class 'str'>) for datapoint `relay_status` in product id `9zynrkxe5tys0rja`, expected one of `['power_off', 'power_on', 'last']`; please report this defect to Tuya support, or create a quirk at https://github.com/home-assistant-libs/tuya-device-handlers
```

## 2. Root Cause Analysis
The Tuya device specification for product `9zynrkxe5tys0rja` expects values `power_off`, `power_on`, or `last`. However, the physical device firmware transmits raw strings `'off'` and `'on'`.

## 3. Impact & Resolution Status
* **Impact**: Warning only; device relay switching functions, but initial state parsing logs errors.
* **Fix Status**: Unknown / Upstream. Requires creating a device quirk mapping in `home-assistant-libs/tuya-device-handlers` upstream repository.
