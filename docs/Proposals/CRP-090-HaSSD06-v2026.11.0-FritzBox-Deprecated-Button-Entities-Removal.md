# CRP-090: FRITZ!Box Deprecated Button Entities Cleanup

## 1. Executive Summary & Intent
Proactively resolve the two active repairs logged in the `fritz` integration before the mandatory breaking change deadline in **Home Assistant Core 10.0.0**:
1. `deprecated_cleanup_button`: Button entity for cleaning up old network devices is superseded by native device management.
2. `deprecated_firmware_update_button`: Button entity for firmware updates is superseded by `update.fritzbox7590_fritz_os`.

## 2. Breaking Change Details
* **Removal Version**: Home Assistant Core `10.0.0`
* **Issue IDs**:
  - `deprecated_cleanup_button`
  - `deprecated_firmware_update_button`
* **Action Required**: Remove references to legacy button entities in dashboards/automations and disable or delete deprecated entities from the entity registry.

## 3. Remediation Plan
1. Audit automations and dashboard cards for references to FRITZ cleanup and update buttons.
2. Remove/disable deprecated entities from entity registry via WebSocket API.
3. Dismiss repair notices and verify clean issue ledger.
