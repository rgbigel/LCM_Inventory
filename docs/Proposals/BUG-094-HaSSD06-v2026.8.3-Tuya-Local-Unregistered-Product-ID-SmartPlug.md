# BUG-094: Tuya Local Unregistered Product IDs in Smart Plug Device Profiles

## 1. Defect Description & Discovery Vector
During local discovery of smart plugs in `tuya_local`, multiple devices log configuration warnings:
```
AV Devices: device product id keym9qkuywghyrvs is not listed in its config (smartplugv2_energy); please report it so support can be improved
Nachttisch: device product id keym9qkuywghyrvs is not listed in its config (smartplugv2_energy); please report it so support can be improved
Ventilator : device product id keyjup78v54myhan is not listed in its config (smartplugv2_energyv3); please report it so support can be improved
```

## 2. Root Cause Analysis
Hardware revisions `keym9qkuywghyrvs` and `keyjup78v54myhan` are fully functional under the `smartplugv2_energy` and `smartplugv2_energyv3` YAML profile configurations, but their specific product IDs are not yet registered in `custom_components/tuya_local/devices/*.yaml`.

## 3. Impact & Resolution Status
* **Impact**: Minor log clutter during initialization.
* **Fix Status**: Unknown / Upstream contribution. Can be resolved by submitting a PR to `make-all/tuya-local` registering the product IDs under the corresponding device config files.
