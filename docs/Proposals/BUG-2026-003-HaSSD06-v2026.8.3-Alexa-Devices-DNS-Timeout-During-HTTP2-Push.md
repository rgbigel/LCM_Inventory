# BUG-2026-003: Alexa Devices HTTP/2 Push DNS Resolution Timeout (`ClientConnectorDNSError`)

## 1. Defect Description & Discovery Vector
During steady-state operation of Home Assistant Core 2026.8.3, `aioamazondevices` logs thousands of recurring warnings and DNS connection errors:
```
aioamazondevices: Failed to refresh communications settings for device Dot Badezimmer, used cached values. (Count: 2,909)
aiohttp.client_exceptions.ClientConnectorDNSError: Cannot connect to host api.amazon.com:443 ssl:default [Timeout while contacting DNS servers]
```

## 2. Root Cause Analysis
`aioamazondevices` utilizes `aiohttp_asyncmdnsresolver` and `aiodns` over an asynchronous HTTP/2 push connection. Under high concurrency on Home Assistant OS (Python 3.14 runtime), local DNS queries to the gateway router intermittently time out when multiple Alexa echo devices push equalizer and DND state events simultaneously.

## 3. Impact & Resolution Status
* **Impact**: Non-fatal; `aioamazondevices` falls back to cached settings. However, it generates significant log noise (2,900+ entries) in system logs.
* **Fix Status**: Unknown / Upstream. Requires an upstream library patch in `aioamazondevices` or configuring persistent DNS server caching / fallback in the Home Assistant network layer.
