# CRP-2026-014: Disable Raspberry Pi Onboard Bluetooth Adapter & Consolidate BLE to Shelly Gateway

## 1. Executive Summary & Intent
Deactivate the onboard Broadcom Bluetooth adapter (`bcm43438-bt` / `hci0`, Config Entry `01KM0AR8WX9XT1S9AFJ92TP3JP`) in Home Assistant Core on `HaSSD06`. All Bluetooth Low Energy (BLE) sensors (Govee H5075 thermo-hygrometers, Shelly BLU TRVs, and BTHome probes) will be consolidated to communicate exclusively via the centrally located **`shellyblugwg3` Shelly BLU Gateway G3** proxy (`01KB11EY1Y2WCQWT3RW058AH38`).

## 2. Hardware Reception & Range Audit
* **Audited Bluetooth Devices**:
  1. `T/H SZ` (Govee H5075: `A4:C1:38:E2:BC:98`)
  2. `SH TRV SZ` (Shelly BLU TRV: `F8:44:77:34:40:6C` — RSSI: `-60 dBm` via Shelly Gateway)
  3. `Sh TRV Bad` (Shelly BLU TRV: `F8:44:77:26:1F:49` — RSSI: `-59 dBm` via Shelly Gateway)
  4. `Sh TRV WZ` (Shelly BLU TRV: `F8:44:77:26:13:A7` — RSSI: `-60 dBm` via Shelly Gateway)
  5. `T/H Bath` & `T/H Terrasse`
* **Zero-Orphan Verification**: The audit confirmed that **100% of all registered BLE devices** have direct, strong radio link margins with the Shelly BLU Gateway G3. Zero devices rely exclusively on the Raspberry Pi.

## 3. Technical Benefits & Stability Improvements
1. **Eliminates Flapping & Micro-Dropouts**: Completely removes the 850+ dual-receiver packet collisions and 1.99s unavailable dropouts identified in `sensor.h5075_bc98_*`.
2. **Relocation Proofing**: Physical relocation of the Raspberry Pi host further away will cause zero degradation to Bluetooth sensor performance.
3. **Resource Efficiency**: Frees Bluetooth HCI background scanning cycles and interrupt load on the Raspberry Pi host.
4. **Reversible**: The config entry can be re-enabled instantly at any time via Home Assistant UI or WebSocket API.

## 4. Execution Plan
1. Send `config_entries/disable` payload via WebSocket API to disable entry ID `01KM0AR8WX9XT1S9AFJ92TP3JP`.
2. Verify that all 33 Bluetooth entities remain online and active with zero dropouts.
3. Refresh `data/subsystem_inventory.json` via `Update-HaInventory.ps1`.
