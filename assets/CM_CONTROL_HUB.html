📖 CM Control Hub User Guide & Operational Manual

1. Two-Tier Proposal & STATUS State Lifecycle

Plan State:

  • 🐛 Bug: Raw error intake / issue feedback below suggested. Can be promoted to Suggested or Approved.
  • 💡 Suggested: Idea registered for review; requires operator approval before execution.
  • Approved: Formally approved; queued for AI agent implementation.
  • ⏸️ Deferred: Postponed to future milestone.
  • ❌ Rejected: Dropped / cancelled.
  • ✅ Completed: Formally reviewed, completed, and committed in Git.

STATUS (Physical Progress):

  • Undecided: Initial unstarted state.
  • Queued (Ready): Approved and placed in implementation queue.
  • ⚡ In Progress: Active implementation / agent development.
  • ⏳ Verification: Implementation complete; awaiting Beyond Compare visual review.
  • 📦 Committed: Visual review completed and local Git commit recorded.
  • ✅ Completed: Formal review disposition COMPLETED.
  • 🚀 Pushed: Committed changes pushed to remote Git tracking branches.

2. Unified CRP Sequence Identifier

All change requests follow the unified identifier standard: CRP-079 (single sequence across all repositories).

3. Beyond Compare Visual Review Gate

Click 🔍 BC to open Beyond Compare with the Variant A baseline:
Left: Workspace_Inventory\scratch\BC_Review\<CRP>_<Repo>_<CommitSha> (Baseline)
Right: Target Repository Working Directory (Current Live)

  • Copy Right → Left: Stages modifications for completion.
  • Type 'Delete' on Left: Permanently deletes file on disk and in Git.
  • Type 'Rename to X' on Left: Renames file and cleans up old file.

4. COMPLETE Gating Invariants

The COMPLETE and COMPLETE SELECTED actions are strictly gated:

  • Only CRPs in ⏳ Verification, ⚡ In Progress, or Approved state can be completed.
  • CRPs in Undecided, Deferred, Blocked, or Rejected state cannot be accidentally completed.

5. Interactive CM Console (Bottom Dock)

Type commands directly into the bottom console to control the CM engine:
do CRP-078 • verify CRP-078 • commit CRP-079 • complete CRP-077 • review CRP-078 • prio CRP-079 H • status • readiness
