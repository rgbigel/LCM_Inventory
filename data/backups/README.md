# Centralized Backup Storage (`LCM_Inventory`)

## Purpose
This directory serves as the centralized, authoritative destination for all backup manifests, snapshot indices, and recovery points generated by the `LCM_Backup` companion subsystem.

## Subdirectory Structure
- `manifests/`: JSON point-in-time state descriptors and checksum files.
- `archives/`: Compressed repository state archives.
- Telemetry logs are stored in `LCM_Inventory/logs/backups/`.
